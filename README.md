# THE LAST EXIT | Escape Room Website

**Every Second Counts. Every Clue Matters.**

## About The Project

THE LAST EXIT is a cinematic, responsive website designed for a physical escape room business.

The website introduces visitors to the escape room experiences, provides information about the business, and allows visitors to contact the team through a contact form interface.

## Website Pages

### 1. Home Page

* Cinematic hero section.
* Introduction to the escape room experience.
* Three escape room experiences:

  * The Haunted House
  * The Secret Lab
  * The Lost Treasure
* How It Works section.
* Call-to-action section.
* Footer with navigation and contact information.

### 2. About Page

* About hero section.
* Who We Are.
* Our Story.
* Our Mission.
* Why Choose Us.
* Call-to-action section.

### 3. Contact Page

* Contact information.
* Contact form interface.
* Location section.
* Navigation and footer.

## Technologies Used

* Dark cinematic visual theme.

* Custom escape room imagery.

## Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Explore the website through the navigation menu.

## Important Note

This project is a static front-end website.

The contact form is a user interface only and does not submit messages to a backend server. Booking and payment functionality are not implemented.
